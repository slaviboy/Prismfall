# Asset licences

An inventory of every asset Prismfall ships, with its origin and licence. Everything under `content/` was created for this project: by the Blender scripts in `assets/blender/scripts/`, by procedural code in this repository, or as renders of the game itself. The exception is the photoscanned models in `content/shared/scans/` (section 5): real-world scans from Poly Haven, released under CC0 1.0 and processed for real-time use. Apart from those, the only third-party material in a build is the npm packages listed in section 10, including the two font packages.

**No assets, audio or code were taken from Tetris Effect or any other game.** The VLC source code was studied for ideas only, as recorded in `AUDIO_ANALYSIS.md`, and no VLC code is included.

`src/stages/assetLicenses.test.ts` checks that every `.glb`, `.png`, `.webp`, `.jpg`, `.ogg`, `.opus`, `.wav` and `.mp3` file under `content/` appears in this document by its repo-relative path. Add a row whenever you add such a file.

There is no `public/` folder. A build contains only what Vite bundles: `src/`, the files under `content/` that the stage registry discovers, and the npm packages.

"Original work for Prismfall" is the licence string used in the asset metadata (`*.meta.json`, `assets.json`). It means the file was created for this project and is not under any third-party licence.
